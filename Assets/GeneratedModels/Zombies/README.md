# Zombie Dummy OBJ Set
Five separate static prototype meshes for Unity:
- Zombie_Fat_Dummy.obj
- Zombie_Dog_Dummy.obj
- Zombie_01_Worker_Dummy.obj
- Zombie_02_Civilian_Dummy.obj
- Zombie_03_Police_Dummy.obj

+Y is up, +Z is forward, coordinates are approximately metres. The meshes include low-poly silhouette, separate material regions, and simple facial/gear details. These are static dummies with no skeleton, rig, or animation. Keep ZombieDummies.mtl beside the OBJ files when importing for material colors.
