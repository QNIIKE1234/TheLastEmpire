# แผนฟีเจอร์ที่ต้องพัฒนาต่อ (Stash Storage & Weapon Modification / Artifact System)

**วันที่บันทึก**: 22 พฤศจิกายน 2026  
**สถานะ**: จดบันทึกไว้สำหรับพัฒนาในรอบถัดไป (Planned)

---

## 1. ระบบคลังเก็บของ (Storage / Stash System)
- สร้างระบบคลังเก็บของกลาง/ตู้เก็บของสำหรับฝาก-ถอนไอเทม อาวุธ ทรัพยากร และ Artifact ออกจากกระเป๋าผู้เล่น
- มีหน้าต่าง UI คลังเก็บของ (รองรับการย้ายของไป-กลับระหว่างกระเป๋าผู้เล่นกับคลังเก็บของ, จัดเรียง/ซ้อน Stack และเซฟข้อมูลร่วมกับ `SaveSystem`)
- พิจารณารองรับการซิงค์ Multiplayer / Save ต่อผู้เล่นหรือต่อฐานในอนาคต

---

## 2. ระบบปรับแต่งอาวุธ & ใส่ Artifact (`Modify Weapon` System)
- **หน้าต่าง UI เฉพาะ (`Weapon Modify Window`)**:
  - เลือกอาวุธที่ต้องการปรับแต่ง (แสดงรุ่นอาวุธ, ค่าสถานะปัจจุบัน vs หลังใส่ Artifact, และช่อง Slot สำหรับติดตั้ง)
  - แสดงรายการ Artifact ที่ผู้เล่นมีและรองรับกับอาวุธชิ้นนั้น สามารถใส่/ถอด/สลับได้สะดวก
- **โครงสร้างสล็อต Artifact**:
  - **อาวุธ 1 ชิ้น สามารถติดตั้ง Artifact ได้สูงสุด `4 ช่อง` (4 Slots)**
- **คลัง Artifact เฉพาะทางต่ออาวุธ**:
  - **อาวุธแต่ละชนิดจะมีชุด Artifact เฉพาะของตัวเองประมาณ `4 – 10 อย่าง`** เพื่อเปลี่ยนสไตล์การเล่น/พฤติกรรมของอาวุธอย่างชัดเจน
  - **ตัวอย่างแนวคิด**:
    - *Sniper Rifle*: Artifact ยิงออกทีละ **2 นัดพร้อมกัน** (Double Shot), เจาะเกราะทะลุศัตรู, นัดสุดท้ายคริติคอลแรงขึ้น ฯลฯ
    - *Shotgun / Rifle / SMG / Bow / Melee*: Artifact เพิ่มจำนวนกระสุน, กระสุนชิ่ง, เพิ่มสถานะธาตุ/พิษ/ไฟ, ดูดเลือด, ลดเวลาบรรจุกระสุน, เพิ่มระยะฟัน ฯลฯ
- **การเชื่อมต่อระบบเซฟ & Multiplayer**:
  - เก็บข้อมูล Artifact ที่ติดตั้งอยู่ในแต่ละอาวุธลง `SaveData` และซิงค์ผลลัพธ์การยิง/ดาเมจใน Co-op Multiplayer
